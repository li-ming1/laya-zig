这个实验在做什么

每一步都是对 Laya 模型（322M，mmBERT-base 22 层 + 决策头）的一次零样本前向： 把盘面写成文本当作 state，四个方向作为四个候选项，各在自己那个 <mask> 位置上打分再 softmax。模型没有在蛇上训练过，所以这里没有任何"它会玩"的保证。

模型卡自报：零样本 typed-decisions 0.342，随机是 0.318。 下面的循环、直接撞死、以及高置信度地选错，都是预期行为而不是运行时故障 —— 前向已被一份独立的纯 Python 参考实现校验到 1e-5。

「候选约束」决定模型被允许答错到什么程度：不约束（0）时它会自己撞死、转圈； 在第 9 档里棋盘先算好一条覆盖全部格子的哈密顿环，只把「沿环走一步」和「不越过尾巴的捷径」 交给它挑 —— 于是无论它怎么答，蛇都会把棋盘填满，剩下的区别只是走了多少步。 这时「赢」说明的是那条环把棋盘撑住了，不是模型学会了玩蛇。

把「决策者」切到贪心/随机/分层/哈密顿环可以看没有模型的基线： 「哈密顿环基线」是同一套规则去掉模型，用来给模型加上去的部分定价。点「跑对照」 让同一批种子跑同一大小的棋盘。
